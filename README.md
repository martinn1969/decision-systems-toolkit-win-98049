## About Decision Systems Toolkit

Decision Systems Toolkit is a browser-based analytics toolkit for practical decision-making tasks. It brings together statistical methods that are commonly used for product experiments, comparison testing, and measurement planning, all without requiring external libraries or a separate runtime.

It is useful for teams and individuals who need quick answers from data in a lightweight interface. The toolkit is designed around common decision workflows such as estimating sample size, comparing means or proportions, and reviewing confidence intervals in a straightforward way.

---

## Features

- Runs entirely in the browser
- A/B test calculator for experiment analysis
- Welch t-test for comparing means
- z-test for comparing proportions
- Sample size estimation for planning tests
- Statistical power analysis for experiment design
- Newcombe confidence intervals for proportion comparisons
- Offline operation with no external libraries

## Usage

Use the toolkit by loading it in a browser and selecting the analysis you need.

Typical workflow:
1. Enter your observed values or experiment results.
2. Choose the appropriate method, such as an A/B test, Welch t-test, or z-test.
3. Review the output for confidence intervals, sample size estimates, or power calculations.
4. Adjust inputs and rerun the calculation as needed.

Example use cases:
- Compare two product variants in an A/B test
- Estimate the sample size needed before running an experiment
- Check statistical power before collecting data
- Measure uncertainty with confidence intervals
